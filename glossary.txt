# 术语表 / Glossary
# 每行「原文=译文」，# 开头是注释；改完重启程序生效。
#
# 生效方式（按词条类型自动分两路，实测调出来的）：
#   拉丁词条（rack / blood money / 人名） → 注入 system，只在句子命中时才注入，最多 5 条。
#       5 种写法各 5 遍实测：10/10 命中、0 污染。
#   中日文词条（再来週 / 先月末） → **预替换**：送进模型前就把原文里的词换掉。
#       注入 system 会让 1.8B 输出韩语（「下下周의会议」），换格式 / 加「只用简体中文」/
#       标「中日对照」全都治不好；预替换 3/3 命中、0 韩文。
#   保底：万一输出里出现韩文而原文没有，会自动去掉术语表重译一次（宁退质量，不上脏字）。
#
# 三点要知道：
#   1. 中日文预替换会改变原文语种（「再来週の」变成「下下周の」），只适合短词条，
#      整句级别的东西别放进来。拉丁词条不预替换，原文照旧。
#   2. --tr-style index（Index-Translate）没有 system，拉丁词条对它无效；
#      中日文词条的预替换仍然有效。
#   3. 匹配规则：拉丁词按词边界（rack 不误中 track / bracket，不区分大小写）；
#      中日文按子串（再来週 命中 再来週の…）。
#
# 最适合放进来的三类：
#   1. 人名 / 角色名 / 队名 / 游戏专有名词 —— 钉住固定译法，免得一句一个样
#   2. 小模型不认识的俚语 —— 如 rack=床（get out of the rack 是起床，四个模型全译成「架子」）
#   3. 固定考点 —— 如 再来週=下下周、先月末=上个月底（1.8B 稳定译错，7B 才对）
#
# 示例（去掉行首的 # 即生效）：
# Dragon = 龙
# Keria = 岷析
# rack = 床
# doped up = 被灌药
# blood money = 血汗钱
# 再来週 = 下下周
# 先月末 = 上个月底
